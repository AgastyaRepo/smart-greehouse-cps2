Kesehatan & Evaluasi Cyber-Physical System

Metrik komunikasi, integritas data, dan deteksi kegagalan perangkat

Total Pesan Diterima 0 Pesan QoS 1 berhasil divalidasi
Estimasi Packet Loss 0.0% 0 nomor urut terlewat
Restart / Reboot Terdeteksi 0 Deteksi reset sequence (bukan packet loss)
Pesan Ditolak (Rejected) 0 Payload korup atau melanggar skema
Latensi Rata-rata -- ms Berdasarkan timestamp tersinkron
Latensi Maksimum -- ms Puncak latensi transmisi jaringan

Catatan Interpretasi Metrik Evaluasi:

  • Deteksi Restart vs Packet Loss: Jika sequence number turun drastis ke angka ≤ 10, sistem mencatatnya sebagai event reboot mikrokontroler, bukan hilang di jaringan.
  • Akurasi Latensi: Timestamp sensor beresolusi detik Unix epoch, sehingga nilai latensi merupakan estimasi dengan toleransi ±1 detik. Jika timestamp = 0 (NTP belum sinkron), latensi sengaja tidak dihitung.
  • Network Fail-Safe: Jika broker terputus, ESP32 beralih ke mode kontrol mandiri (mode: offline) tanpa menghentikan aktuasi fisis.
